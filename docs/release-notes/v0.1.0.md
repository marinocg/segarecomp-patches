# segarecomp Patches v0.1.0: first widescreen collection

## Read before installing

* Schema 2 packages contain **executable C11 source** that is compiled into the Patched program. It is **not sandboxed**, and SHA-256 is an integrity check, not publisher authentication. Install only if you trust this repository.
* Target: 16:9. A segarecomp build with the patch installer and native patch SDK is required (on the product's `main`; not in v0.7.0).
* Sonic 1, Sonic 2 and Sonic 3 & Knuckles change gameplay slightly (actors become active in the widened margins). Sonic 3 & Knuckles is verified for the Sonic route of the lock-on composite only; some backgrounds use the VDP's wrapped scenery and small visual glitches are possible; no full-campaign guarantee is made. Streets of Rage 2 only adds enemies in the margins (no native scenery or HUD relocation).

## Provenance

* Collection source: this repository at the commit the `v0.1.0` tag points to.
* Provider sources and BPS deltas under `patches/genesis/*/source/` are byte-identical to the `provider.c` and `game.bps` inside each package (digests in `release.json`).
* Packages were built by the maintainer's private authoring workflow (opaque revision ids in `release.json`) with `tools/segapatch.py`, and checked with the shipped `segarecomp patch inspect|verify` against the exact images (maintainer-attested; aggregate evidence only).

Not included: presentation-only and validation-only packages, and earlier prototypes.
