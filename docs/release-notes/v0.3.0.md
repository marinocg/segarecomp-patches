Package SHA-256 digests are in `SHA256SUMS` and in the catalog. The collection version `v0.3.0` is unrelated to the package versions. Install only one of the three for a given image.

## What they do

* **Widescreen** for the stated aspect ratio: the game's own picture stays 320 pixels wide and untouched; the package supplies authored scenery beside it in the verified scrolling scenes, and the host's generic extension elsewhere.
* **Actors beside the picture**, drawn with the game's own art, priority and palettes.
* **Early object activation (gameplay-changing).** Layout objects farther from the camera are created earlier, sized for the aspect ratio, so enemies and items are not missing at the wider edges.
* **Practice+** (optional, player-invoked): A+B+C together while a verified level runs restores Mickey's power to full.

## Is gameplay modified?

**Yes.** Unlike the presentation-only `castle-of-illusion-widescreen-practice` package in v0.2.0, these variants change which layout objects exist and when. Enemy contact and damage events can therefore differ from the original. Items, collisions, RNG effects, boss completion and natural level progression were not verified.

## Read before installing

* This is **executable C11 source plus guest code** compiled into the Patched program. It is **not sandboxed**, and a SHA-256 is an integrity check, not publisher authentication. You approve the exact package identity when you install it; install only what you trust.
* **Requires segarecomp v0.9.0 or later** (schema 3 / native ABI 2). The packages are built with product revision `8d419ab`. See <https://github.com/marinocg/segarecomp-patches/blob/main/docs/installation.md>.
* A different image, region or revision is refused by digest.
* Evidence tier: synthetic-only in this repository; real-image checks were done locally by the maintainers. CI never uses a commercial image.
